# Hackathon_DataWizards_2026
Our team hackathon for Data Wizards with Meet, Sudev, Rythem and Tanveer

This website tracks accidents around the world, and users will able to report new accidents.

From the streets of Edmonton to the cities around the globe, the Edmonton Accident Tracker monitors and informs the situations of various types of accidents.

The user gives information to the website, which then updates it in real time, to provide all users with accurate infromation for the best possible experience.

Ensures that all citizens are well informed about the conditions of the roads, and well prepared.

Turning raw data from the streets into a real-time shield for the world.

Data Wizards has worked extremely hard to come up with a solution to rebuild the 511 website to make it more optimized.
